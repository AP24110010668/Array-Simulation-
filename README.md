Array Simulation in C

## Description
A simple C program to simulate array operations like insert, delete, search, and display.  
The program demonstrates how arrays work and how elements shift during insertions and deletions.

## Features
- Insert an element at any position  
- Delete an element from any position  
- Search for a value  
- Display the current array  
- Exit the program

## How to Run
1. Make sure GCC is installed.  
2. Open terminal in the project folder.  
3. Compile the code -> gcc array.c -o array.exe
4. Run the program -> ./array.exe
5. Follow the menu to perform operations.

## Notes
- Maximum array size: 50 elements  
- Positions are 1-based (first element = position 1)  
- Program shows element shifts during insert/delete
